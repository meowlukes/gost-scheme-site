# Блок-схема из кода Pascal по ГОСТ 19.701-90

Сайт принимает программу на Pascal / Object Pascal (Lazarus, Delphi, консольные программы)
и строит схемы программы по ГОСТ 19.701-90 и правилам методички: отдельная схема для
программы и для каждой подпрограммы, нумерация блоков, подписи «Да»/«Нет», циклы,
переносы, комментарии. Схему можно править мышью и сохранить в PNG, SVG, JPEG, WebP и PDF
на белом или прозрачном фоне.

Сайт полностью статический: вся работа идёт в браузере пользователя, сервер только отдаёт
файлы. Базы данных, PHP, Node.js на сервере не нужны. Правки пользователя хранятся
в его браузере (localStorage).

## Что в папке

```
index.html          готовый сайт — этот файл и открывают в браузере
fonts/              шрифты PT Sans, PT Mono, Tinos и fonts.css
vendor/             библиотеки jsPDF и JSZip
src/                исходники (из них собирается index.html)
  shell.html        разметка и стили страницы
  parser.js         разбор текста на Pascal
  transform.js      перевод операторов в текст блоков (формулы, ввод/вывод, условия)
  layout.js         раскладка схемы по правилам ГОСТ и методички
  project.js        список схем, обозначения, комментарии, проверки
  render.js         отрисовка: SVG на экране, растровый экспорт, DPI в файлах
  app.js            интерфейс: редактор кода, правка схемы, экспорт
  examples.js       примеры программ
build.py            сборка index.html из src/
tests/              проверка движка в Node.js
nginx.conf.example  пример настройки nginx
Dockerfile          запуск в контейнере nginx
```

На сервер нужно выложить только `index.html`, `fonts/` и `vendor/`. Остальное нужно,
если вы захотите что-то менять.

## Запуск

**Проверить у себя на компьютере.** В папке проекта выполните

```
python3 -m http.server 8080
```

и откройте http://localhost:8080. Можно открыть `index.html` и двойным щелчком, но тогда
браузер может не подгрузить локальные шрифты (ограничение для file://) и возьмёт
системные — схема построится, но размеры текста будут чуть другими.

**Обычный хостинг или Apache.** Скопируйте `index.html`, `fonts/` и `vendor/` в корень сайта
(например, `public_html` или `/var/www/html`). Больше ничего настраивать не нужно.

**nginx.** Скопируйте файлы в `/var/www/gost-scheme`, возьмите за основу `nginx.conf.example`,
укажите свой домен и перезапустите nginx: `sudo nginx -t && sudo systemctl reload nginx`.

**Docker.**

```
docker build -t gost-scheme .
docker run -d -p 8080:80 --name gost-scheme gost-scheme
```

**Бесплатные статические хостинги** (GitHub Pages, Netlify, Cloudflare Pages, Vercel):
загрузите папку целиком, команда сборки не нужна, корень публикации — папка проекта.

### HTTPS

Кнопка «Копировать PNG в буфер обмена» работает только на странице по HTTPS
(или на localhost) — таково требование браузеров. Всё остальное работает и по HTTP.
Для бесплатного сертификата на своём сервере подойдёт certbot:
`sudo certbot --nginx -d scheme.example.ru`.

## Как внести изменения

1. Правьте файлы в `src/` (например, добавьте свой пример в `examples.js` или поменяйте
   цвета в `shell.html`).
2. Соберите страницу: `python3 build.py` (нужен Python 3.8+). Появится новый `index.html`.
3. Проверьте движок без браузера: `node tests/engine-test.js` (нужен Node.js 18+) —
   скрипт разберёт все примеры и выведет блоки каждой схемы.
4. Выложите обновлённый `index.html` на сервер.

Порядок файлов при сборке задан в `build.py` и важен: каждый следующий файл пользуется
функциями предыдущих.

## Полезно знать

- Сохранённое состояние (код, правки схем, обозначения, настройки экспорта) лежит
  в localStorage под ключом `gost-pascal-scheme-v1`. Если изменить формат данных,
  смените ключ в `src/app.js`, чтобы у пользователей не всплыли старые данные.
- Размер холста по умолчанию ограничен 170 × 245 мм (лист А4 с полями). Высоту колонки
  до переноса можно поменять в «Настройках построения» прямо на сайте.
- PNG и JPEG сохраняются с записанным разрешением (150/300/600 dpi), поэтому Word
  вставляет рисунок в натуральную величину.
