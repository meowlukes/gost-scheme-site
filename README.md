# Блок-схема из кода Pascal по ГОСТ 19.701-90

Сайт принимает программу на Pascal / Object Pascal (Lazarus, Delphi, консольные программы)
и строит схемы программы по ГОСТ 19.701-90 (ИСО 5807-85): отдельная схема для программы
и для каждой подпрограммы, идентификаторы символов, подписанные выходы «Решений», циклы,
переносы через соединители, комментарии. Схему можно править мышью и сохранить в PNG, SVG,
JPEG, WebP и PDF на белом или прозрачном фоне.

Сайт полностью статический: программа пользователя обрабатывается в его браузере и на
сервер не отправляется, сервер только отдаёт файлы. Правки хранятся в браузере
(localStorage). Единственное внешнее обращение — счётчик Яндекс.Метрики (настраивается
в `site.config.json`, см. «Полезно знать»).

## Соответствие стандарту

Разбор стандарта по пунктам и таблица «требование → где реализовано → чем проверено» —
в [docs/GOST-19.701-90.md](docs/GOST-19.701-90.md), сверка с методичкой по слайдам —
в [docs/METHOD.md](docs/METHOD.md), отчёт об аудите кода — в [docs/AUDIT.md](docs/AUDIT.md). Коротко:

| Что в программе | Символ | Пункт ГОСТ |
|---|---|---|
| начало и конец схемы | Терминатор | 3.4.2 |
| ввод, вывод, сообщение об ошибке | Процесс (как в методичке) или Данные — по настройке | 3.2.1.1 / 3.1.1.1 |
| вычисление | Процесс | 3.2.1.1 |
| вызов подпрограммы из этой же программы | Предопределённый процесс | 3.2.2.1 |
| `if`, `while`, `repeat` | Решение, выходы подписаны | 3.2.2.4 |
| `case` | одно Решение с несколькими подписанными выходами | 3.2.2.4, 4.3.1 |
| `for` | Граница цикла, обе части с одним идентификатором | 3.2.2.6 |
| перенос в другую колонку | парные Соединители | 3.4.1, 4.2.5 |
| пояснения обозначений | Комментарий | 3.4.3 |

Набор символов для ввода/вывода, вызова подпрограмм и `case` переключается
в «Настройках построения».

  core/               движок, не зависит от браузера
    parser.js           разбор текста на Pascal

    svg.js, canvas.js   вывод сцены в SVG и на Canvas, DPI в PNG/JPEG
  ui/                 интерфейс: редактор кода, правка схемы, экспорт
scripts/build.mjs     сборка index.html из src/
tests/                тесты (node --test): эталон раскладки, правила ГОСТ, символы, case
docs/                 исследование стандарта и отчёт об аудите

На сервер нужно выложить только `index.html`, `fonts/` и `vendor/`.

## Запуск

**Проверить у себя на компьютере.** В папке проекта выполните

```
python3 -m http.server 8080
```

и откройте http://localhost:8080. Можно открыть `index.html` и двойным щелчком, но тогда
браузер может не подгрузить локальные шрифты (ограничение для file://) и возьмёт
системные — схема построится, но размеры текста будут чуть другими.

**Обычный хостинг или Apache.** Скопируйте `index.html`, `fonts/` и `vendor/` в корень сайта
(например, `public_html` или `/var/www/html`). Больше ничего настраивать не нужно.

**nginx.** Скопируйте файлы в `/var/www/gost-scheme`, возьмите за основу `nginx.conf.example`,
укажите свой домен и перезапустите nginx: `sudo nginx -t && sudo systemctl reload nginx`.

**Docker.**

```
docker build -t gost-scheme .
docker run -d -p 8080:8080 --name gost-scheme gost-scheme
```

**Бесплатные статические хостинги** (GitHub Pages, Netlify, Cloudflare Pages, Vercel):
загрузите папку целиком, команда сборки не нужна, корень публикации — папка проекта.

### HTTPS

Кнопка «Копировать PNG в буфер обмена» работает только на странице по HTTPS
(или на localhost) — таково требование браузеров. Всё остальное работает и по HTTP.
Для бесплатного сертификата на своём сервере подойдёт certbot:
`sudo certbot --nginx -d scheme.example.ru`.

## Как внести изменения

Нужен Node.js 20 или новее.

```
npm ci            # один раз: инструменты сборки и проверки
npm run build     # собрать index.html и vendor/ из src/
npm test          # тесты движка
npm run lint      # проверка кода
npm run verify    # всё вместе + проверка, что index.html соответствует src/
```

1. Правьте файлы в `src/`. Размеры символов, отступы и шрифты схемы меняются только
   в `src/gost/metrics.js`, форма символов — только в `src/gost/symbols.js`.
2. Выполните `npm run verify`.
3. Выложите обновлённые `index.html`, `fonts/`, `vendor/` на сервер.

`index.html` хранится в репозитории, чтобы сайт можно было выложить без сборки, но правится
он только через `src/` — проверка в CI не пропустит расхождение.

## Полезно знать

- Сохранённое состояние (код, правки схем, обозначения, настройки) лежит в localStorage
  под ключом из `src/ui/config.js`. При чтении оно проверяется (`src/ui/state.js`):
  повреждённые или устаревшие данные заменяются значениями по умолчанию.
- Размер листа по умолчанию — 170 × 245 мм (А4 с полями), задаётся в `src/gost/metrics.js`.
  Высоту колонки до переноса можно поменять в «Настройках построения» на сайте.
- ГОСТ 19.701-90 не задаёт размеров символов, толщины линий и шрифта — это параметры
  оформления. По умолчанию: символ 40 × 20 мм, сетка 5 мм, Times New Roman.
- PNG и JPEG сохраняются с записанным разрешением (150/300/600 dpi), поэтому Word
  вставляет рисунок в натуральную величину.
- Счётчик Яндекс.Метрики задаётся в `site.config.json` (`analytics.yandexMetrika`).
  Чтобы отключить его, поставьте `"enabled": false` и пересоберите страницу. При
  включённом `webvisor` Метрика записывает действия посетителя на странице, включая
  ввод в редактор кода, — учитывайте это в политике конфиденциальности сайта.
