## 5a. Что осталось и почему

1. **Пересечение при досрочном выходе из цикла устранить нельзя без соединителей.** Тело цикла
   замкнуто линией возврата с одной стороны и линией выхода с другой, поэтому линия `exit`
   из тела обязана пересечь одну из них. Стандарт пересечения допускает (п. 4.2.2); чек-лист
   показывает их число.
2. **Ветвь с `exit`/`break`/`continue` не выносится** при нехватке высоты: её переходы привязаны
   к месту. Такая ветвь по-прежнему может выйти за лист — чек-лист это показывает.
3. **`try … except`** в общем случае схемой не выражается: исключение может возникнуть в любом
   операторе. Обработчик показывается только для ввода с проверкой числа, иначе — замечание.
4. **`src/ui/app.js`** остаётся крупным модулем (~900 строк): управление листом и боковой панелью
   завязано на общее состояние. Теперь он закрыт тестом в браузере.
5. **PDF — растровый**; лист со схемой не управляется с клавиатуры без мыши.

- `npm run lint` — без замечаний;
- `npm test` — 95 тестов, все проходят (включая преобразование, устойчивость и правку линий);
- `npm run test:ui` — 6 сценариев в браузере: примеры, своя программа, правка мышью, экспорт, сохранение;
- подробнее о первом этапе:
  - *эталон раскладки*: при прежнем наборе символов новая параметрическая раскладка даёт

  запуск с повреждённым сохранением — ошибок в консоли нет.
